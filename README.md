# txyz-main-theme

Tema del lloc principal de troposfera.xyz.

Carpeta buida de moment. El contingut vindrà de `txyz-2025-main-theme`, que es
queda al costat com a còpia de seguretat fins que el nou estigui actiu al
WordPress.

El nom de la carpeta va pla per als scripts. El `»` viu al `Theme Name:` de la
capçalera de `style.css`, que és el que es veu a l'escriptori de WordPress.
